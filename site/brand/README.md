# Kraken Cards branding

The official Kraken Cards logo was sourced from the store's public early-access storefront:

- Store: https://krakencards.eu/
- Asset: https://vykupkariet.sk/brand/kraken-logo.png

The logo's transparent outer padding was trimmed and the artwork resized, without redrawing, recoloring, or changing its proportions. The main copy is encoded as lossless WebP; the favicon is a smaller PNG. Assets are served locally, not hotlinked.

Kraken Cards retains ownership of its branding. Included at the store owner's request for this tournament timer. The font licenses elsewhere in this project do not apply to these assets.
