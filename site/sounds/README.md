# Round-end sound

`pokemon-item-received.mp3` is the approximately 2.25-second item-found / item-received jingle from Pokémon Red/Blue/Yellow, used at the user's request when the round timer reaches zero.

- Source page: https://www.myinstants.com/en/instant/pokemon-item-found-50824/
- Source audio: https://www.myinstants.com/media/sounds/pokemon-red_blue_yellow-item-found-sound-effect.mp3
- The source clip is self-hosted without modification; no third-party scripts or embeds are included.

Pokémon audio belongs to its respective rights holders, not this project. This attribution does not grant a general reuse license, and the font licenses in this repository do not cover the audio.

The overtime-limit alert and the unavailable-clip fallback are generated locally using Web Audio.
